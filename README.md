# Multi-Agent Collaboration System (C++)

## 📌 项目简介
本项目基于 C++ 实现一个多 Agent 协同系统，模拟真实 AI Agent 工作流：

- Planner Agent：任务拆解
- Worker Agent：执行任务
- Review Agent：结果汇总

---

## 🚀 系统流程

User Input  
→ Planner（任务拆解）  
→ Worker（执行任务）  
→ Review（总结输出）

---

## 🧠 特点
- 多 Agent 协作结构
- 调度器控制流程
- 模拟 AI 工作流
- 控制台可运行

---

## ▶️ 运行方式
使用 Visual Studio 2022 打开并运行 main.cpp
